# 🎡 Wheel of Fortune Addon for Blender

[![Blender 4.0+](https://img.shields.io/badge/Blender-4.0%2B-orange.svg)](https://www.blender.org/)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

Интерактивный генератор и аниматор Колеса Фортуны для Blender. Позволяет параметрически настраивать геометрию колеса, стрелки, текста и процедурно запекать физику движения стрелки и отката.

![Preview](docs/preview.gif) <!-- Добавьте сюда GIF или скриншот работы аддона -->

---

## ✨ Основные возможности

* **Параметрическая геометрия:** Настройка радиуса, толщины колеса, пинов, спиц и геометрии стрелки прямо из UI.
* **Управление секторами:** Динамический список секторов с настройкой весов и индивидуальных имён.
* **Процедурный 3D-текст:** Автоматическая подгонка размера и выравнивание текста под размер секторов.
* **Физика и Анимация:** Симуляция затухания, жесткости пружины стрелки и подшаговый расчёт (substepping) для максимальной точности на высоких скоростях.
* **Локализация:** Поддержка русского и английского языков интерфейса Blender.

## 📥 Установка

1. Скачайте архив `wheel_tool-vX.X.X.zip` со страницы **[Releases](../../releases)** (НЕ используйте кнопку *Code -> Download ZIP*).
2. Откройте Blender и перейдите в **Edit > Preferences > Add-ons**.
3. Нажмите кнопку **Install...** (или **Install from Disk** в Blender 4.2+) в правом верхнем углу.
4. Выберите скачанный `.zip` архив и установите галочку напротив **Wheel Generator**.

---

## 🚀 Быстрый старт

1. Откройте **3D Viewport** и нажмите клавишу `N`, чтобы открыть боковую панель.
2. Перейдите во вкладку **Wheel Tool**.
3. Добавьте нужные сектора во вкладке **Sectors (Dictionary)**.
4. Нажмите **Create wheel** для генерации меша.
5. Настройте физику и нажмите **Make animation** для запекания ключевых кадров.

## ⚙️ Настройки физики стрелки

| Параметр | Описание |
| :--- | :--- |
| **Moment of Inertia** | Момент инерции стрелки (влияет на тяжесть вращения) |
| **Attenuation Coeff** | Коэффициент затухания (трение в шарнире стрелки) |
| **Spring Stiffness** | Жесткость пружины, возвращающей стрелку в центр |
| **Substep Calculation** | Количество микро-шагов симуляции на 1 кадр (повышает точность) |
